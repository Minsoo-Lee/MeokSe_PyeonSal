여러 날 한번에

1
인사말 + 진행 현황을 한 줄로모바일에서는 따로따로 쌓였던 두 블록을 데스크탑에서는 좌우로 나란히 배치. 화면이 넓으니 굳이 세로로 쌓아둘 필요가 없음.
3
다음 메뉴 하이라이트모바일은 세로(뱃지→제목→설명→버튼), 데스크탑은 가로(아이콘+텍스트 묶음 | 버튼)로. 내용은 완전히 동일, 배치만 가로로.
4
즐겨찾기 — 3열 그리드가로 스크롤 대신 3개를 한 줄에 다 보여줌 (모바일은 공간이 없어서 가로 스크롤이 필요했던 것).
5
바로가기 타일 — 사이드바처럼즐겨찾기 옆에 세로로 붙여서 "보조 패널"처럼. 2:1 비율(grid-template-columns: 2fr 1fr)이라 즐겨찾기가 주인공, 타일은 옆에서 보조.
!
구현 관련 메모지금 코드 기준으로는 Tailwind 반응형 클래스(lg: prefix) 몇 개만 추가하면 됨 — IngredientCheckPage에서 이미 lg:grid-cols-2로 이런 식의 레이아웃 전환을 쓰고 있어서 패턴은 똑같이 가져다 쓸 수 있음. 새 컴포넌트 구조가 필요한 게 아니라 CSS 브레이크포인트만 얹는 정도.
